# Installation

## Requirements

- Python 3.12
- uv (recommended) or pip

## Install

From the repository root:

```bash
uv sync --all-groups
```

## Configuration

Application settings are loaded via `settings` (environment variables). For local development, copy or adapt `.env` examples if present in the repo, or set variables documented for your environment.
